摘要

心理語言學文獻中的「詞語聯想」（word association）具有相當特定的意義。（一般而言，如果 nurse〔護士〕出現在 doctor〔醫師〕這類高度相關的詞之後，受試者對它的反應會比平常快。）我們將擴展這個詞的意義，作為以統計方式描述各種值得研究的語言現象之基礎。這些現象包括 doctor/nurse 類型的語意關係（實詞／實詞），以及動詞與介系詞之間的詞彙句法共現限制（實詞／功能詞）。本文將根據資訊理論中的互資訊概念，提出一項客觀量度，用以從電腦可讀的語料庫估計詞語聯想常模。（取得詞語聯想常模的標準方法，是讓數千名受試者接受數百個詞的測試；這種方法既昂貴，也不可靠。）我們提出的量度稱為「關聯比」（association ratio），直接從電腦可讀的語料庫估計詞語聯想常模，使數萬個詞的常模估計成為可能。

1意義與聯想

語言學通常不只根據詞義，也根據詞與其他詞的共現情形來分類詞語。例如，貫穿整個 Firth 學派傳統的主張，就是「從一個詞相伴出現的詞語，便能認識這個詞」（Firth，1957）。

一方面，bank 會與 money〔金錢〕、notes〔鈔票〕、loan〔貸款〕、account〔帳戶〕、investment〔投資〕、clerk〔行員〕、official〔主管〕、manager〔經理〕、robbery〔搶劫〕、vaults〔金庫〕、working in a〔在一家……工作〕、its actions〔其行動〕、First National〔第一國民……〕、of England〔英格蘭的……〕等詞語或表達方式共現。另一方面，我們也發現 bank 會與 river〔河流〕、swim〔游泳〕、boat〔船〕、east〔東〕（當然還有已各自取得特殊意義的 West 與 South）、on top of the〔在……上方〕以及 of the Rhine〔萊茵河的……〕共現。（Hanks，1987，第 127 頁）

尋找愈來愈細緻的詞語類別並不是新事。以詞典編纂為例，至少可以追溯至 Hornby 的《高階學習者詞典》（Advanced Learner's Dictionary，初版於 1948 年）所描述的「動詞句型」。新出現的條件是，近年來，利用電腦儲存與分析大量自然語言資料的能力已有顯著進展。因此，我們正逐漸能以更嚴謹的方式檢驗並運用這類非形式化的論斷，看看我們的詞語實際上都與哪些詞相伴出現。

2實務應用

本文提出的統計描述有許多可能相當重要的應用，包括：

  1. 為語音辨識與光學字元辨識（OCR）的語言模型提供限制條件。
  2. 在剖析名詞複合詞、並列結構、介系詞片語等高度歧義的句法結構時，提供消歧線索。
  3. 從大型資料庫（例如報紙、專利）中檢索文本。
  4. 提高計算語言學家編製詞彙句法知識詞庫的效率。
  5. 提高詞典編纂者辨識一般用法與慣常用法的效率。

以光學字元辨識的應用為例。假設我們有一套如 Kahan 等人（1987）所述的 OCR 系統，它認為辨識結果是 farm 或 form 的機率大致相同，而上下文是以下兩者之一：（1）federal ___ credit；（2）some ___ of。

  • federal {farm / form} credit
  • some {farm / form} of

我們提出的關聯量度可以利用這項事實來消除歧義：第一種上下文中，farm 出現的可能性高得多；第二種上下文中，則是 form 出現的可能性高得多。請注意，其他依賴詞性等句法限制的消歧方法，在這個例子裡不太可能有所幫助，因為 form 與 farm 都經常用作名詞。

3詞語聯想與心理語言學

眾所周知，詞語聯想常模是心理語言學研究的重要因素，尤其是在詞彙提取方面。一般而言，當 nurse 出現在 doctor 這類高度相關的詞之後，受試者對它的反應會比平常快。

以下概述一些反應時間實驗的結果及其意涵。在這些實驗中，受試者或者（a）將依序呈現的字母串分類為詞與非詞，或者（b）把這些字母串念出來。對詞語（例如 BUTTER〔奶油〕）而言，這兩類反應在前面出現相關詞（例如 BREAD〔麵包〕）時，都一致快於前面出現無關詞（例如 NURSE〔護士〕）的情況。（Meyer 等人，1975，第 98 頁）

這類心理語言學研究，大多以詞語聯想常模的實證估計為基礎，例如 Palermo 與 Jenkins（1964）的研究。這可能是同類研究中最具影響力的一項，儘管其涵蓋範圍非常小，而且年代也有些久遠。該研究測量了 200 個詞，方法是請數千名受試者，在每個待測詞之後各寫下一個詞。結果以表格呈現，列出受試者寫下了哪些詞、各有多少人寫下，並依年級與性別分組。例如，該書第 98–100 頁指出，與 doctor 最常聯想到的詞是 nurse，其次是 sick〔生病〕、health〔健康〕、medicine〔醫藥〕、hospital〔醫院〕、man〔男人〕、sickness〔疾病〕、lawyer〔律師〕，以及另外約 70 個詞。

4以資訊理論為基礎的量度

我們以資訊理論的「互資訊」（mutual information）概念為基礎，提出另一種測量詞語聯想常模的量度：關聯比。[1] 相較於 Palermo 與 Jenkins（1964）採用的主觀方法，這項量度更加客觀，成本也更低。關聯比可以擴大應用，為語言中的大量詞彙提供穩健的詞語聯想常模估計。以關聯比衡量，與 doctors 關聯最強的前五個詞依序是：dentists〔牙醫師〕、nurses〔護士〕、treating〔治療中〕、treat〔治療〕與 hospitals〔醫院〕。

什麼是「互資訊」？根據 Fano（1961），若兩個點（詞）x 與 y 的機率分別為 P(x) 與 P(y)，則它們的互資訊 I(x,y) 定義為：

I(x,y)=\log_2\frac{P(x,y)}{P(x)P(y)}

概略來說，互資訊比較的是同時觀察到 x 與 y 的機率（聯合機率），與分別獨立觀察到 x 及 y 時的機率乘積（偶然共現的基準）。若 x 與 y 確實有關聯，聯合機率 P(x,y) 就會遠大於偶然共現機率 P(x)P(y)，因此 I(x,y)\gg 0。若 x 與 y 之間沒有值得關注的關係，則 P(x,y)\approx P(x)P(y)，所以 I(x,y)\approx 0。若 x 與 y 呈互補分布，P(x,y) 就會遠小於 P(x)P(y)，使得 I(x,y)\ll 0。

在我們的應用中，詞機率 P(x) 與 P(y) 的估計方式，是計算語料庫中觀察到 x 與 y 的次數，即 f(x) 與 f(y)，再除以語料庫大小 N 進行正規化。（我們的例子使用了數個大小不同的語料庫：1987 年美聯社〔AP〕語料庫有 1,500 萬詞，1988 年 AP 語料庫有 3,600 萬詞，經標記的語料庫則有 860 萬個詞次〔tokens〕。）聯合機率 P(x,y) 的估計方式，是計算在含有 w 個詞的視窗中，y 出現在 x 之後的次數 f_w(x,y)，再除以 N 進行正規化。

譯註：此處的 1988 年 AP 語料庫大小，原文寫為 3,600 萬詞；後文與部分表格則使用 4,400 萬詞，另有精確值 44,344,077。本文依各處原文保留。

視窗大小這個參數，讓我們能從不同尺度觀察。較小的視窗可以辨識固定表達方式（如 bread and butter 這類慣用語）及其他作用於短距離的關係；較大的視窗則能凸顯語意概念，以及其他作用於較大範圍的關係。

表 1 有助於呈現這個差異。[2] 在 bread and butter、drink and drive 等固定表達方式中，所關注的兩個詞之間距離固定，變異數很小。在 1988 年 AP 語料庫中，只要這些詞彼此接近（在五個詞的範圍內），它們的位置差就恰好都是兩個詞。也就是說，平均距離為 2，變異數為 0。

複合詞的詞序也非常固定（變異數很小），但平均距離較接近一個詞，而不是兩個詞。相較之下，man/woman 這類關係比較不固定，這可由較大的距離變異數看出。（man/women 的平均距離接近 0，表示兩種先後順序出現的次數大致相等。）詞彙關係則有數種類型：有些像 refraining from，相當固定；有些像 coming from，中間可能隔著一個論元；還有些像 keeping from，中間幾乎一定隔著一個論元。

每種情況的理想視窗大小各不相同。本文其餘部分採取折衷作法，將視窗大小 w 設為五個詞；這個範圍夠大，足以呈現動詞與論元之間的某些限制，又不致大到掩蓋那些依賴嚴格相鄰關係的限制。[3]

由於次數很少時，關聯比會變得不穩定，因此我們不討論 f(x,y)\leq 5 的詞對。可行的改進方式是使用 t 分數，剔除未達顯著水準的詞對。可惜，這需要估計 f(x,y) 的變異數，超出本文的範圍。因此，本文其餘部分採用這個簡單但任意設定的門檻，忽略出現次數很少的詞對。

嚴格來說，關聯比與互資訊有兩點差異。第一，聯合機率理應具有對稱性：P(x,y)=P(y,x)，因此互資訊也具有對稱性：I(x,y)=I(y,x)。然而，關聯比並不對稱，因為 f(x,y) 記錄了線性先後順序。（請記得，f(x,y) 表示在含有 w 個詞的視窗中，詞 x 出現在 y 之前的次數，而不是兩個詞以任意順序出現的次數。）雖然我們可以重新定義 f(x,y)，使其具有對稱性（將矩陣與其轉置矩陣取平均），但我們決定不這麼做，因為順序資訊似乎相當值得研究。請留意表 2 各詞對的不對稱性。這些數值是從 1988 年 AP 文本的 4,400 萬詞計算而得，呈現了從性別偏見到句法等各式各樣的偏向。

第二，一般可能預期 f(x,y)\leq f(x) 且 f(x,y)\leq f(y)，但以我們目前的計數方式，如果 x 與 y 恰巧在視窗中出現多次，就不一定如此。例如，1988 年 4 月 1 日的一則 AP 報導出現以下句子：

Library workers were prohibited from saving books from this heap of ruins.
圖書館工作人員被禁止從這堆廢墟中搶救書籍。

在這裡，f(\mathrm{prohibited})=1，而 f(\mathrm{prohibited},\mathrm{from})=2。將 f(x,y) 除以 w-1 即可修正這個問題（相當於從我們的關聯比分數中減去 \log_2(w-1)=2）。這項調整還有另一個好處，就是確保：

\sum f(x,y)=\sum f(x)=\sum f(y)=N

當 I(x,y) 很大時，關聯比會產生相當可信的結果，與 Palermo 和 Jenkins（1964）所報告的結果頗為相似，如表 3 所示。相對地，當 I(x,y)\approx 0 時，這些詞對就比較不值得關注。（我們觀察到一項很粗略的經驗法則：I(x,y)>3 的詞對通常值得關注，而 I(x,y) 較小的詞對通常不是如此。可以用主觀量度校準這項量度，使這個說法更精確。另一個方法是估計變異數，進而對信賴水準作出陳述，例如：以 95% 的信心水準認為 P(x,y)>P(x)P(y)。）

若 I(x,y)\ll 0，我們會預測 x 與 y 呈互補分布。然而，我們很少能觀察到 I(x,y)\ll 0，因為語料庫太小，而且測量方法也太粗略。例如，假設 x 與 y 在每百萬詞的文本中都約出現 10 次，則 P(x)=P(y)=10^{-5}，而偶然共現機率為 P(x)P(x)=10^{-10}。因此，要說 I(x,y) 遠小於 0，就必須能說 P(x,y) 遠小於 10^{-10}；以目前可取得的語料庫大小，很難對這種陳述有充分信心。事實上，我們無法輕易觀察到小於 1/N\approx 10^{-7} 的機率，因此，除非偶然共現機率本身很大，否則很難判定 I(x,y) 是否表示遠低於偶然共現基準的情況。（事實上，表 3 中的詞對 a … doctors，出現頻率顯著低於偶然共現的預期值。但要支持這項陳述，我們必須補償視窗大小的影響，將分數向下調整 2.0，例如從 0.96 降為 −1.04；同時，還需要用 Good〔1953〕之類的方法估計標準差。）[4]

5詞彙句法規律

雖然心理語言學文獻已相當詳細地記錄 doctor/nurse 等名詞／名詞聯想的重要性，對於動詞、功能詞、形容詞與其他非名詞之間的關聯，卻相對少有討論。除了辨識 doctor/nurse 這類語意關係，我們也認為，關聯比可以用來尋找動詞與其典型論元或附加語之間值得關注的詞彙句法關係。我們提出的關聯比，可以視為 Sinclair 以下論述的形式化版本：

含有 set 的片語動詞有多常見？Set 特別容易與 about、in、up、out、on、off 等詞結合，而這些詞本身也非常常見。Set off 出現的可能性有多高？兩者都是高頻詞［每百萬詞中，set 約出現 250 次，off 約出現 556 次……］。我們提出的問題，大致可以改寫為：off 緊接在 set 之後出現的可能性有多高？……這是 0.00025\times 0.00055［P(x)P(y)］，得到一個很小的數字：0.0000001375……這項計算背後的假設，是詞語隨機分布於文本中［用我們的術語來說，就是偶然共現］。語言學家顯然知道情況並非如此；要粗略衡量 set 與 off 彼此吸引的程度，可以把這個機率與實際發生的情形比較……在 730 萬詞的語料庫裡，set off 出現了近 70 次［P(x,y)=70/(7.3\times 10^6)\gg P(x)P(y)］。這已足以顯示其主要模式，也意味著，在現有語料庫中，應能找到足夠的證據來描述相當多的片語……（Sinclair，1987c，第 151–152 頁）

使用 Sinclair 的估計值 P(\mathrm{set})\approx 250\times 10^{-6}、P(\mathrm{off})\approx 556\times 10^{-6}，以及 P(\mathrm{set},\mathrm{off})\approx 70/(7.3\times 10^6)，我們可以估計互資訊為：

I(\mathrm{set};\mathrm{off}) =\log_2\frac{P(\mathrm{set},\mathrm{off})}{P(\mathrm{set})P(\mathrm{off})} \approx 6.1

在 1988 年 AP 語料庫中，N=44,344,077；我們估計 P(\mathrm{set})\approx 13,046/N、P(\mathrm{off})\approx 20,693/N，以及 P(\mathrm{set},\mathrm{off})\approx 463/N。利用這些估計值，算出的互資訊為 I(\mathrm{set};\mathrm{off})\approx 6.2。

至少在這個例子裡，不同語料庫得到的數值似乎相當接近。在其他例子中，我們會看到取樣造成的差異。Sinclair 的語料庫是一個相當平衡的文本樣本，主要來自英式英語；AP 語料庫則是美式新聞文體的不平衡樣本。

Set 與 off 之間的這種關聯相當強；其聯合機率超過偶然共現機率的 2^6=64 倍。Sinclair 提到的其他小品詞，其關聯比如表 4 所示。

6以詞性標記器進行前處理

含有介系詞 to 的片語動詞帶來一個值得研究的問題，因為它可能與不定詞標記 to 混淆。我們發現，若先使用 Church（1988）之類的方法，替語料庫中的每個詞標記詞性，再測量帶有標記的詞之間的關聯，就能辨識兩類動詞之間值得關注的對比：一類與後接的介系詞 to/in 相關，另一類則與後接的不定詞標記 to/to 相關。（詞性記號取自 Francis 與 Kučera〔1982〕：in＝介系詞；to＝不定詞標記；vb＝原形動詞；vbg＝動詞加 -ing；vbd＝動詞加 -ed；vbz＝動詞加 -s；vbn＝動詞加 -en。）關聯比辨識出相當多與 to 具有值得關注之關係的動詞；如果只看分數達 3.0 以上的詞對，與介系詞 to/in 相關的動詞有 768 個，與不定詞標記 to/to 相關的動詞有 551 個。在 to/in 之前，關聯最強的十個動詞如下：

  • to/in：alluding/vbg、adhere/vb、amounted/vbn、relating/vbg、amounting/vbg、revert/vb、reverted/vbn、resorting/vbg、relegated/vbn。
  • to/to：obligated/vbn、trying/vbg、compelled/vbn、enables/vbz、supposed/vbn、intends/vbz、vowing/vbg、tried/vbd、enabling/vbg、tends/vbz、tend/vb、intend/vb、tries/vbz。

譯註：原文稱「十個」，但實際在 to/in 後列出 9 項，在 to/to 後列出 13 項；此處完整保留原列舉。

由此可見，對語料庫進行前處理，並調整所採用的詞項集合，可以帶來相當大的效益。

7以句法剖析器進行前處理

Hindle（Church 等人，1989）發現，先用 Fidditch 句法剖析器（Hindle，1983a、1983b）處理輸入資料，有助於辨識動詞與論元之間的關聯，並以此為基礎推定名詞的語意類別。如表 5、表 6 所示，Hindle 的方法能找出一些相當值得研究的關聯。

Hindle 用剖析器處理 1988 年 AP 語料庫（4,400 萬詞）後，找到了 N=4,112,943 個主詞／動詞／受詞（SVO）三元組。動詞與受詞之間的互資訊，是以這 400 萬個三元組為基礎，計算動詞與受詞出現在同一三元組中的頻率，再與偶然共現的基準相比而得。例如，disconnect/V 與 telephone/O 的聯合機率是 7/N。在這個例子中，偶然共現機率是 (84/N)\times(481/N)，因為有 84 個 SVO 三元組的動詞為 disconnect，而有 481 個 SVO 三元組的受詞為 telephone。互資訊為：

\log_2\frac{7N}{84\times 481}=9.48

同樣地，drink/V 與 beer/O 的互資訊為：

9.9=\log_2\frac{29N}{660\times 195}

（drink/V 與 beer/O 分別出現在 660 個及 195 個 SVO 三元組中，其中有 29 個三元組同時包含兩者。）

8詞典編纂上的應用

大型機器可讀語料庫直到現在才開始能供詞典編纂者使用。此前，詞典編纂者不是仰賴人工閱讀所蒐集的引例，就是使用只有約一百萬詞的小型語料庫。前者帶有選擇性，因此難免造成偏差：罕見詞與罕見用法會被蒐集，常見詞的常見用法卻不會。後者則只能對少數最高頻英語詞彙的最常見用法，提供可靠資訊。（像 Brown Corpus 這種百萬詞語料庫，大致只能對約 4,000 個詞條的部分詞形之部分用法，提供可靠資訊。然而，一般詞典的詞條數通常是這個數量的 20 倍。）

目前可用來研究機器可讀語料庫的電腦工具，仍然相當初步。這些工具是語料索引程式（concordancing programs，見圖 1），基本上就是 KWIC（key word in context，上下文關鍵詞；Aho 等人，1988）索引，再加上擴大上下文、向左或向右排序等功能。互動式軟體非常少。1980 年代詞典編纂的典型情形是：詞典編纂者拿到某個詞的語料索引，在列印稿上用彩色筆標示，以辨識主要詞義，接著撰寫句法描述與釋義。

相較於由人工閱讀來蒐集一箱箱引例索引卡，這種技術已有很大進步；一個世紀以前，Murray 編纂《牛津英語詞典》時採用的正是前一種方法。但這種技術只有在一個詞不超過數十條索引行、而且主要詞義只有兩三種時，才運作良好。當分析 take、save 或 from 這類複雜的詞時，詞典編纂者必須從成千上萬條索引行、也就是一頁又一頁的電腦列印稿中，找出隱藏的顯著模式與細微差異。沒有工具輔助的人腦，根本無法發現所有重要模式，更不用說將它們分組並依重要性排序。

在這樣的語料索引中，很難判斷哪些現象重要、哪些不重要。例如，從圖 1 選出的索引行很容易看出，to 經常出現在 save 之前，the 經常出現在 save 之後；但只靠檢視語料索引，很難判定這兩種共現現象究竟是一種、兩種都具有意義，還是都沒有。

以下兩個例子將說明，關聯比量度如何讓分析更快，也更準確。

8.1例一：「save … from」

表 7 的關聯比顯示，關聯常模不只適用於實詞，也適用於功能詞。例如，與 save 有顯著關聯的詞之一就是 from。許多詞典，例如 Merriam Webster 出版的《韋氏新大學詞典》第九版（Webster's Ninth New Collegiate Dictionary），都沒有在 save 詞條中明確提到 from；英國的學習者詞典則會特別指出 save 與 from 的關係。相較於美國的大學詞典，這些學習者詞典更重視語言結構與搭配，而受英國傳統訓練的詞典編纂者，通常也相當擅長察覺這類概括性規律。然而，釐清這些事實、區分正確與錯誤的直覺，需要大量時間與辛勤工作，而且很容易出現不一致與遺漏。

8.2例二：辨識語意類別

確立 save … from 的相對重要性，並注意到這兩個詞很少相鄰之後，我們現在希望加快這項耗費大量人力的工作：將語料索引行分類。理想上，我們希望開發一組半自動工具，協助詞典編纂者產出類似圖 2 的結果；圖 2 對 save … from 的 65 條索引行提供了附帶標註的摘要。[5] 在 save 的 666 條索引行中，約有 10% 出現 save … from 這個模式。

傳統上，人們對語意類別只有模糊的認識；至今，投入大型語料庫系統性分類的心力仍然很少。詞典編纂者往往憑印象使用語料索引；語意理論家、人工智慧研究者及其他人，則專注於少數有趣的例子，例如 bachelor〔單身漢〕，很少思考如何把這些結果擴展到更大的規模。

基於這個考量，一個合理的問題是：這 65 條 save … from 索引行，與 save 的所有其他用法究竟有多契合？為回答這個問題，我們進行了繁重的語料索引分析。接近完成時，我們發現，為了掌握概括性規律而設計的標籤，多半只要看看 save 的關聯比表中列出的詞項，就能得到提示。例如，在分析 save 時，我們未能注意到時間副詞語的重要性，而且也沒有詞典記載這一點。然而，從上面的關聯比表應該可以清楚看出，annually〔每年〕與 month〔月〕[6] 經常和 save 一起出現。更仔細的檢視顯示，時間副詞語只與 save 的某一組受詞具有值得關注的關係，也就是那些被標記為 [MONEY] 的受詞。AP 通訊稿中充滿了 saving $1.2 billion per month〔每月節省十二億美元〕之類的討論；如果這類模式具有普遍性，計算詞典編纂就應予以測量並記錄，即使傳統詞典沒有這麼做。

另一個例子也能說明，關聯比表原本可以如何幫助我們分析 save 的索引行。我們曾考慮用 ENV(IRONMENT)〔環境〕這個語意標籤，分析以下例句：

本文關於 save 與其他詞的所有敘述，可能只適用於 1987 年的美式新聞文體。不過，從直覺上看，所發現的許多模式似乎都很有可能是一般英語的慣常用法。未來可以檢視其他更平衡的語料庫，測試這些模式在其中是否仍然成立。

9結論

本文從心理語言學的詞語聯想常模概念出發，將它延伸至資訊理論中的互資訊定義。這提供了一種精確的統計計算方法，能應用於極大型文本語料庫，產生包含數萬個詞的關聯表。接著，我們展示了這張表如何記錄許多相當值得研究的模式，從 doctor … nurse 到 save … from 都包括在內。最後，我們說明關聯比表中的模式，如何協助詞典編纂者整理語料索引。

事實上，我們得到這些結果的過程，基本上與本文的敘述順序相反。語料索引分析仍然極為耗費人力，也很容易發生遺漏。語料索引的排序方式，無法充分支援目前的詞典編纂實務。雖然語料索引是以單一詞為索引鍵，詞典編纂者實際上卻往往利用第二個詞，例如 from，或者像時間副詞語這種同樣常見的語意概念，來決定如何分類索引行。換句話說，他們利用兩個詞來對詞義進行「三角定位」（triangulate）。這種三角定位方法，主要根據用法，也就是分布證據，將索引行聚集為不同詞義，而不是依據對意義的直覺。因此，即使標籤集合看起來帶有語意值，「什麼構成一個詞義」這個問題，仍可用句法方法（符號操作）來處理，而不必處理語意（詮釋）。

三角定位方法需要「技藝」。詞典編纂者如何判定哪些潛在的切分依據值得關注，哪些只是偶然造成的？我們提出的關聯比分數，提供了一種實用而客觀的量度，往往能相當接近這種「技藝」的判斷。由於這項量度是客觀的，它可以系統性地應用於大量資料，持續提升一致性與生產力。

不過，客觀分數也可能造成誤導。分數只考慮分布證據。例如，這項量度給 set … for 的評價高於 set … down；它不知道前者較不值得關注，因為其語意具有組合性，可以由組成部分推得。此外，這項量度非常表面；如果沒有 Church 的詞性程式或 Hindle 的剖析器這類明確的前處理，它就無法把詞語聚集為適當的句法類別。然而，這兩種前處理都無法凸顯 picture 與 photograph 這類名詞之間「自然」的相似性。雖然我們或許能設想某種對這個特定例子有幫助的前處理，但很可能永遠存在一類概括性規律：對有判斷力的詞典編纂者而言顯而易見，卻完全超出電腦客觀處理所能掌握的範圍。

儘管有這些問題，關聯比仍可能成為協助詞典編纂者的重要工具，作用有點像語料索引的索引。它可以幫助我們決定該找什麼，並迅速概述我們的詞語究竟與哪些詞相伴出現。
